# Chrome Web Store listing — Prism

Paste into Developer Dashboard → Store listing. The name and short summary come from
`public/_locales/<lang>/messages.json` in the uploaded zip, so only the description goes here.

## Description

```
Pick any color on your screen in one click, then check it, save it and use it.

🎯 PICK
• Click Pick Color (or press Alt+Shift+C, then Enter) and Chrome's precise eyedropper appears, with a magnifier to land on the exact pixel
• Works anywhere on your screen: web pages, images, even other apps
• Every color in HEX, RGB, HSL and OKLCH; click a format to copy it

♿ CHECK
• WCAG contrast checker with AA / AAA results for text and UI
• Color-blindness preview: protanopia, deuteranopia, tritanopia

🎨 SAVE AND USE
• History of your last 200 colors
• Palette sessions: collect colors into a palette as you browse
• Export palettes to Tailwind, CSS/SCSS, JSON or a PNG image

🔒 PRIVATE AND LIGHT
• Asks for one permission: storage. No access to the sites you visit, no install warning
• No account, no tracking, no network requests. Everything stays in your browser
• 13 languages

New in 1.2: no more "read and change data on all websites" permission, the keyboard
shortcut works on every page, and picking works anywhere on your screen.
```
